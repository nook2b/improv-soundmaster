# CLAUDE.md — AI-звукарь для импров-шоу

Контекст для Claude Code. Общайся с пользователем (Иван) по-русски.

## Что это

Система, которая во время импров-шоу слушает и смотрит сцену и ставит звуковые эффекты, музыку и
атмосферу из утверждённой библиотеки: сначала подсказывает технику, затем — автономно для
проверенных случаев. Полный план и принятые решения — `PLAN.md` (ревизия 4, разд. 3.1 — выбранная
архитектура); инструкция для пользователя — `README.md`.

## Решения, которые уже приняты (не пересматривать без пользователя)

- **Язык шоу — русский.** Площадка — Грузия (OpenAI и Gemini API там доступны). Команда согласна на запись и отправку в облако.
- **Компьютер — Mac M2.** Камера — Logitech Brio 4K. Микшера и петличек пока нет: звук сцены с **рекордера у сцены** (слышит и колонки, и зал). Петлички/микшер/многоканальный интерфейс — потом, через профиль входа (`config/inputs/*.yaml`), без изменения кода.
- **Архитектура — «каскад»:** распознавание речи локально (Whisper large-v3-turbo через MLX) → быстрые правила по словам из реестра → облачная модель (GPT-5 mini или Gemini Flash; текст реплик + состояние сцены + редкий кадр → строгий JSON с действиями) → контроллер. Live API — только как вариант для сравнения (дороже: ~$10–30/ч против ~$0,5–4/ч).
- **Цель — автономность.** Человек наблюдает и держит «Стоп AI». Громкие эффекты (выстрел, взрыв) и отбивки по умолчанию запускает только человек — это решение команды, пересматривается по статистике. С рекордером (нет чистого звука актёров) автозапуск AI в зал выключен кодом (`no_clean_actor_feed`) до замеров проникновения колонок.
- **«Монтаж»:** актёр быстро проходит перед сценой → новая сцена → фон прошлой гаснет, новый выбирает модель. Детектор по камере, режимы OFF / SUGGEST / AUTO.
- **Музыка:** библиотека файлов + потоковая генерация (Lyria RealTime — экспериментальный адаптер; Mubert — вариант). Генератором управляет программа по пресетам из реестра, не модель свободным текстом; при сбое — плавный переход на файл.

## Устройство кода (`soundmaster/`)

| Модуль | Что делает |
|---|---|
| `registry.py` + `config/registry.yaml` | Реестр эффектов и музыкальных состояний: режим OFF/SUGGEST/AUTO, класс sync/context/background, риск, клавиши, слова-подводки/триггеры. Громкие не могут быть AUTO. |
| `controller.py` | Все правила допуска: устаревание сцены/соединения, опоздание, дубли, лимиты, подсказки с истечением, взведение/срабатывание, «монтаж». Однопоточный — вызывать из asyncio-цикла. |
| `audio/mixer.py`, `engine.py` | Микшер в аудио-callback (шины, ducking, лимитер, fade); предзагрузка звуков; время «команда → звук». |
| `audio/inputs.py` + `config/inputs/` | Профили входа: роли каналов `stage_mix / actor_mic / actors_aux / room / reference`. |
| `audio/devices.py`, `audio/recording.py` | sounddevice (вход/выход), запись дорожек на общих часах. |
| `music/` | Источник музыки: файлы или генератор (test_tone, lyria_realtime) с резервом. |
| `media/vad.py`, `media/asr.py` | Нарезка речи на фразы (принудительный разрез длинной речи), распознавание (mlx / faster / scripted), фильтр «галлюцинаций» Whisper. |
| `media/scenecut.py` | Детектор «монтажа» по кадрам. |
| `media/ffmpeg.py`, `media/download.py` | Чтение файлов и камеры (avfoundation) через ffmpeg; скачивание по ссылке через yt-dlp. |
| `fastrules.py` | Слова-подводки/триггеры с отрицаниями и отменами. |
| `brain/` | Инструкция модели, схемы ответа, адаптеры OpenAI/Gemini (HTTP), планировщик запросов, бюджет. |
| `listener.py` | Связывает звук/кадры → фразы → текст → правила и модель → контроллер. |
| `replay.py`, `report.py` | Прогон записи «как вживую» (реальный темп или быстрый без облака) + `report.html`. |
| `app.py`, `panel/` | Сборка из `config/show.yaml`, веб-пульт на localhost (aiohttp + WebSocket). |

## Команды

```bash
python -m pytest                                   # все тесты (без звуковой карты; replay-тестам нужен ffmpeg)
python -m soundmaster make-test-sounds             # тестовые звуки (sounds/ не в git)
python -m soundmaster run [--input mac-mic|brio-mic] [--null-audio]
python -m soundmaster replay ЗАПИСЬ.mp4|ССЫЛКА --asr mlx [--brain openai|gemini] [--max-seconds N] [--fast]
python -m soundmaster devices | cameras | check
```

На Mac: `pip install -e ".[files,asr-mac,dev]"`, `brew install ffmpeg yt-dlp`. Ключи — только
переменные окружения `OPENAI_API_KEY` / `GEMINI_API_KEY`, никогда не в файлы и не в журнал.

## Правила работы

- Меняешь поведение — добавь или обнови тест; перед коммитом `python -m pytest`.
- Работа через ветки и PR в `main`; PR не сливать без согласия пользователя.
- `recordings/` и `sounds/` не коммитить: там голоса актёров/зрителей и лицензируемые звуки.
- Аудио-callback не должен блокироваться: никаких файлов, сети и журнала внутри `Mixer.render`.
- Ручной пульт должен работать при любом сбое AI, сети, входа или камеры.
- Модель не управляет конфигурацией, громкостью, записью и светом; её ответ — только действия из реестра.

## Что дальше

1. Прогнать реальные записи (`replay`) на Mac с `--asr mlx`, затем с `--brain`; по отчётам настроить
   инструкцию модели (`brain/prompt.py`), правила, пороги VAD и «монтажа».
2. Эталонная разметка записей (`required / acceptable / forbidden`) и автоматический подсчёт точности/полноты.
3. Проверить живой режим на Mac: вывод звука, вход рекордера, камера Brio, задержки.
4. Замерить проникновение колонок в рекордер — от этого зависит, можно ли включать автозапуск без петличек.
