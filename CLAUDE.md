# CLAUDE.md — AI-звукарь для импров-шоу

Контекст для Claude Code. Общайся с пользователем (Иван) по-русски.

## Что это

Система, которая во время импров-шоу слушает и смотрит сцену и ставит звуковые эффекты, музыку и
атмосферу из утверждённой библиотеки: сначала подсказывает технику, затем — автономно для
проверенных случаев. Полный план и принятые решения — `PLAN.md` (ревизия 4, разд. 3.1 — выбранная
архитектура); инструкция для пользователя — `README.md`.

## Решения, которые уже приняты (не пересматривать без пользователя)

- **Язык шоу — русский.** Площадка — Грузия (OpenAI и Gemini API там доступны). Команда согласна на запись и отправку в облако.
- **Компьютер для шоу — Mac M2** (ноутбук); разработка и проверки — также на Windows (`--asr faster`, камера через DirectShow). Камера — Logitech Brio 4K. Микшера и петличек пока нет: звук сцены с **рекордера у сцены** (слышит и колонки, и зал). Петлички/микшер/многоканальный интерфейс — потом, через профиль входа (`config/inputs/*.yaml`), без изменения кода.
- **Архитектура — «каскад»:** распознавание речи локально (Whisper large-v3-turbo через MLX) → быстрые правила по словам из реестра → облачная модель (GPT-5 mini или Gemini Flash; текст реплик + состояние сцены + редкий кадр → строгий JSON с действиями) → контроллер. Live API — только как вариант для сравнения (дороже: ~$10–30/ч против ~$0,5–4/ч).
- **Цель — полная автономность: человек в шоу не участвует**, только держит «Стоп AI» на крайний случай (решение Ивана, 2026-10-04).
  - **Музыка — автоматически** (`autonomy.music: AUTO`), в том числе с рекордером. **Атмосфера места (ресторан, кафе, дождь) — только вручную** (`ai: false` в реестре): гул толпы под речь и музыку давал слишком много шума (решение Ивана, 2026-10-06); модель её не видит. Модель выбирает музыку из словаря `music_vocabulary` (жанр/настроение/энергия/темп/инструмент), а не свободным текстом; генератор — Lyria RealTime. **Музыка только сольная** (`solo` в словаре, решение Ивана, 2026-10-10): жанр задаёт характер, инструмент обязателен (20 вариантов). **Медленно и без барабанов/баса** (`base_config`: bpm 66 на всё шоу — постоянный bpm не сбрасывает контекст Lyria; после прослушки 2026-10-16 «слишком быстро»: 50 из 76 в брак).
  - **Тишины нет:** шоу начинается с нейтральной музыки. **«Монтаж» — AUTO:** новая сцена → сразу нейтральная переходная музыка → как только модель поняла сцену, генератор плавно (~8 с) перетекает в выбранную. Первый выбор в сцене можно поправить через 10 с, дальше — не чаще 30 с.
  - **Разнообразие:** в соседних сценах инструмент не повторяется (`same_as_prev_scene`), модель видит давно не звучавшие инструменты. Инструмент закрепляется за сценой после первого выбора и его уточнения: поворот меняет настроение/энергию, а не инструмент.
  - **Пул записей** (`music_pool`, `sounds/pool/`, `make-music-pool`): записывает **ElevenLabs Music v2.5** (план композиции с `negative_styles`; выиграл слепое сравнение 2026-10-21 вместе с Lyria RealTime — Lyria остаётся для живой генерации, решение Ивана). Как промптить — `docs/music-prompting.md`. **Нейтральный фон — 15 мелодий на разных инструментах** (70% сцен — обычные современные, без особых эмоций), остальные жанры — по 4 настроения; петли 30 с, вырез 2–5 кГц, рядом `.json` с запросом. Строка пула: `настроение/энергия/темп/инструмент [| уточнение]` (регистр вне голоса, способ игры). Готовые записи не замедлять — только перезапись (решение Ивана). Инструменты — стереотипные для жанра (вестерн — губная гармошка, фэнтези — лютня/флейта/колёсная лира). Ручные кнопки жанров на пульте (повтор — следующая, плавно; AI не перебивает до новой сцены) и резерв без интернета (тот же жанр/инструмент; генератор пробуется снова через минуту). `--engine lyria` — запись через Lyria RealTime.
  - **Ключи:** `OPENAI_API_KEY` — «мозг» (GPT-5 mini, выбран по сравнению 2026-10-04: ~$0,4–0,5/ч, ответ ~0,9 с); `GEMINI_API_KEY` — генератор музыки Lyria; `ELEVENLABS_API_KEY` — только запись пула.
  - **Эффекты пока только подсказки.** Автозапуск — после того, как точность на размеченных записях дойдёт до порога: в прогоне 2026-10-04 у OpenAI был правдоподобен ~1 эффект из 16. Громкие эффекты и отбивки — только человек. С рекордером автозапуск эффектов закрыт кодом (`no_clean_actor_feed`).
- **«Монтаж»:** актёр быстро проходит перед сценой → новая сцена → фон прошлой гаснет, новый выбирает модель. Детектор по камере, режимы OFF / SUGGEST / AUTO. **Решает обученная на разметке модель** (решение Ивана, 2026-10-28; `scene_cut.kind: people`), в два шага: уверена через 1 с — сразу; сомневается — музыка приглушается, через 3 с подтверждение или возврат. Смена сцены слышна: музыка проваливается (~−18 дБ, не в тишину), генератор сразу (без плавного перехода) переключается на нейтральную, через ~3 с новая музыка поднимается.
- **Музыка:** потоковая генерация (Lyria RealTime: поток проверен на реальном ключе, первый звук ~3 с; Mubert — вариант) + файлы как резерв. Генератором управляет программа по словарю из реестра, а не модель свободным текстом; при сбое — файл настроения или тишина. Короткий обрыв связи с Lyria (переподключение) закрывает «мостик»: повторяются последние ~6 с музыки (до 30 с), потом плавный переход на новый звук.

## Устройство кода (`soundmaster/`)

| Модуль | Что делает |
|---|---|
| `registry.py` + `config/registry.yaml` | Реестр эффектов и музыкальных состояний: режим OFF/SUGGEST/AUTO, класс sync/context/background, риск, клавиши, слова-подводки/триггеры. Громкие не могут быть AUTO. Словарь музыки `music_vocabulary` → пресет генератора. |
| `controller.py` | Все правила допуска: устаревание сцены/соединения, опоздание, дубли, лимиты, подсказки с истечением, взведение/срабатывание, «монтаж», автоматическая музыка (`music_mode`, `music_min_hold`). Однопоточный — вызывать из asyncio-цикла. |
| `audio/mixer.py`, `engine.py` | Микшер в аудио-callback (шины, ducking, лимитер, fade); предзагрузка звуков; время «команда → звук». |
| `audio/inputs.py` + `config/inputs/` | Профили входа: роли каналов `stage_mix / actor_mic / actors_aux / room / reference`. |
| `audio/devices.py`, `audio/recording.py` | sounddevice (вход/выход), запись дорожек на общих часах. |
| `music/` | Источник музыки: файлы или генератор (test_tone, lyria_realtime) с резервом; `pool.py` — запись пула мелодий (ElevenLabs или Lyria). |
| `media/vad.py`, `media/asr.py` | Нарезка речи на фразы (принудительный разрез длинной речи), распознавание (mlx / faster / scripted), фильтр «галлюцинаций» Whisper. |
| `media/scenecut.py`, `media/peoplecut.py` | Детектор «монтажа»: старый по пикселям и новый — обученная модель по людям в кадре (YOLO в своём потоке, `FrameWorker`). Два шага: через 1 с `cut` (сразу новая сцена) или `dip` (музыка приглушается), через 3 с `confirm` / `reject` (музыка возвращается) / `late_cut`. Без YOLO — пиксельный. |
| `learn/` | Обучение детектора «монтажа»: `collect.py` — сбор примеров с YouTube без сохранения видео (YOLO + `FastTracker`, кандидаты «прошёл поперёк кадра» из `passes.py`), `label.py` — одна локальная страница разметки: видео во встроенном плеере YouTube, поверх рамки людей (жёлтая — на кого среагировала программа; B — указать нужного кликом → `tracks.json`), таймлайн шоу, прогресс по видео, пропущенные монтажи (M → `manual.json`). Ролики mp4 не нарезаются (только `--save-clips`). `model.py` — модель (случайный лес sklearn → деревья в JSON, на шоу sklearn не нужен; `config/scenecut_model.json`); признаки для обучения считаются тем же `LivePasses`, что на шоу (без заглядывания вперёд). Рамки и разметка — `data/scenecut/` (в git); `ignore.json` — отрезки видео без учёта монтажей (разминка на занятии): не на разметке и не в обучении; `sync.py` — сбор и страница сами коммитят только `data/scenecut`, делают `git pull --no-rebase` и `push` (Ивану не нужно набирать git; `--no-push` — выключить). Перед работой с разметкой — `git pull`. |
| `media/ffmpeg.py`, `media/download.py` | Чтение файлов и камеры (avfoundation) через ffmpeg; скачивание по ссылке через yt-dlp. |
| `fastrules.py` | Слова-подводки/триггеры с отрицаниями и отменами. |
| `brain/` | Инструкция модели, схемы ответа, адаптеры OpenAI/Gemini (HTTP), планировщик запросов, бюджет. |
| `listener.py` | Связывает звук/кадры → фразы → текст → правила и модель → контроллер. |
| `replay.py`, `report.py` | Прогон записи «как вживую» (реальный темп или быстрый без облака) + `report.html`. |
| `app.py`, `panel/` | Сборка из `config/show.yaml`, веб-пульт на localhost (aiohttp + WebSocket). |

## Команды

```bash
python -m pytest                                   # все тесты (без звуковой карты; replay-тестам нужен ffmpeg)
python -m soundmaster import-sounds ПАПКА          # свои звуки (mp3/mp4/wav…, имя = id) → sounds/ (не в git)
python -m soundmaster make-test-sounds             # тестовые звуки для недостающих
python -m soundmaster make-music-pool [--only noir/2 --force]  # пул сольных мелодий (ElevenLabs) → sounds/pool/
python -m soundmaster run [--input mac-mic|brio-mic] [--null-audio]
python -m soundmaster replay ЗАПИСЬ.mp4|ССЫЛКА --asr mlx [--brain openai|gemini] [--max-seconds N] [--fast]
python -m soundmaster collect-scenecuts ПЛЕЙЛИСТ [--only-shows] [--limit N]  # примеры «монтажа» (YOLO) → data/scenecut/
python -m soundmaster label-scenecuts             # разметка роликов в браузере → data/scenecut/labels.json
python -m soundmaster train-scenecut              # модель «монтажа» → config/scenecut_model.json (нужен scikit-learn)
python -m soundmaster devices | cameras | check
```

На Mac: `pip install -e ".[files,asr-mac,dev]"`, `brew install ffmpeg yt-dlp`. Ключи — только
переменные окружения `OPENAI_API_KEY` / `GEMINI_API_KEY`, никогда не в файлы и не в журнал.

## Правила работы

- Меняешь поведение — добавь или обнови тест; перед коммитом `python -m pytest`.
- Работа через ветки и PR в `main`; PR не сливать без согласия пользователя.
- `recordings/` и `sounds/` не коммитить: там голоса актёров/зрителей и лицензируемые звуки.
- Аудио-callback не должен блокироваться: никаких файлов, сети и журнала внутри `Mixer.render`.
- Ручной пульт должен работать при любом сбое AI, сети, входа или камеры.
- Модель не управляет конфигурацией, громкостью, записью и светом; её ответ — только действия из реестра.
